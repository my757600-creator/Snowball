# ⛄ 눈싸움 퀴즈 배틀

선생님이 방을 열고 학생들이 접속하는 실시간 개인전 눈싸움 퀴즈 게임입니다.

## 여는 주소
- 깃허브 페이지: `https://<깃허브아이디>.github.io/<저장소이름>/snowball/`
- 학생은 '학생으로 참가하기' → 참가 코드 5자리 → 이름·캐릭터 선택
- 선생님은 첫 화면 아래 '선생님용' → 비밀번호 → 과목 선택 → 방 만들기

## 선생님 비밀번호 바꾸기
`index.html`에서 `const TEACHER_PASSWORD='7777';` 줄의 숫자를 바꾸고 다시 올리면 됩니다.

## 문제 양식 (엑셀·CSV)
A열 문제 · B열 정답 · C~E열 오답 (O/X 문제는 정답 O, 오답 X).
엑셀 시트를 과목별로 만들어 올리면 시트 이름이 과목 이름이 됩니다.

## 참고
- 게임 중에는 선생님 창을 닫거나 최소화하지 마세요 (선생님 화면이 게임 서버 역할).
- 주소 끝에 `?debug`를 붙이면 장애물 충돌 영역이 빨간색으로 보입니다.
